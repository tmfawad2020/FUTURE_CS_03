# Password Strength Analyzer

Cyber Security Internship — Password Security Task.

## Objective
Build a browser-based tool that evaluates user-entered passwords and teaches basic password-security concepts.

## Features
- Checks password length.
- Checks uppercase, lowercase, numbers, and special characters.
- Detects common passwords.
- Detects simple repeated/sequential patterns.
- Considers character diversity/uniqueness.
- Gives practical improvement suggestions.
- Generates a stronger 18-character example.
- Performs all analysis locally in the browser; passwords are not stored or transmitted.
- Responsive interface for desktop and mobile.

## How to run
1. Open `index.html` in a browser.
2. Enter a test password.
3. Review the score and individual checks.
4. Use **Generate** for a stronger example.

No server, database, or installation is required.

## Security notes
This project is an educational analyzer, not a replacement for a production password policy. A real application should use server-side validation, rate limiting, MFA, secure password hashing such as Argon2id/bcrypt/scrypt, and breached-password screening.

The optional old-password reuse feature is intentionally not implemented here because storing recoverable passwords is unsafe. A production system should compare securely derived password identifiers/hashes according to its authentication architecture rather than keeping plaintext passwords.

## Basic cryptography concepts learned
- Passwords should never be stored as plaintext.
- Password hashing is different from reversible encryption.
- A cryptographic password hash should use a password-specific, salted, slow hashing algorithm.
- Strong passwords are preferably long, unique, and generated by a password manager.
